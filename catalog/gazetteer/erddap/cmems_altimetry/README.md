# CMEMS Global Ocean Physics — 2-D fields (MLD, bottom T, SSH, sea ice)

STAC Collection describing (not mirroring) the `cmems_altimetry` ERDDAP griddap dataset. Two-dimensional daily-mean fields from the CMEMS global ocean physics analysis and forecast (1/12 degree): mixed layer depth (mlotst), sea bottom temperature (tob) and salinity (sob), sea surface height (zos), sea floor pressure (pbo) and sea ice variables. The re-served time axis is irregular (about every 2-3 days), not monthly.

- Producer: Copernicus Marine Service (CMEMS) / Mercator Ocean International (https://marine.copernicus.eu).
- Source server: `https://erddap.marine.usf.edu/erddap` (USF IMaRS; config [USF-IMARS/erddap-config](https://github.com/USF-IMARS/erddap-config)).
- Server used here: `https://erddap.oceanmetrics.io/erddap` (re-served with CORS + Parquet).
- Coverage: 2022-06-01 to 2025-05-18, irregular time steps, 0.083333° grid, latitude **ascending**.
- Variables: `sialb` (Mean albedo over sea ice, percent); `siage` (Mean sea ice age, years); `siconc` (Ice concentration, 1); `ist` (sea ice surface temperature, degree_C); `sivelo` (Sea ice speed, m s-1); `sithick` (Sea ice thickness, m); `sisnthick` (Surface snow thickness, m); `mlotst` (Mixed Layer Depth (|dT| = 0.01 wrt 10m), m); `pbo` (Sea Water Pressure at Sea Floor, dbar); `sob` (Sea bottom salinity, 1e-3); `zos` (Sea surface height, m); `tob` (Sea bottom temperature, degree_C); `usi` (Sea ice eastward velocity, m s-1); `vsi` (Sea ice northward velocity, m s-1).
- License/attribution: other (https://marine.copernicus.eu/user-corner/service-commitments-and-licence); attribute as "E.U. Copernicus Marine Service Information (CMEMS)".
