# MODIS-Aqua net primary productivity (VGPM) — monthly global 9 km

STAC Collection describing (not mirroring) the `moda_npp_mo_glob` ERDDAP griddap dataset. Monthly net primary productivity (npp) from the Vertically Generalized Production Model (VGPM) applied to MODIS-Aqua, Oregon State University Ocean Productivity, 9 km global.

- Producer: Oregon State University Ocean Productivity (VGPM, from NASA MODIS-Aqua) (http://sites.science.oregonstate.edu/ocean.productivity/).
- Source server: `https://erddap.marine.usf.edu/erddap` (USF IMaRS; config [USF-IMARS/erddap-config](https://github.com/USF-IMARS/erddap-config)).
- Server used here: `https://erddap.oceanmetrics.io/erddap` (re-served with CORS + Parquet).
- Coverage: 2002-07-31 to 2023-12-31, step P1M, 0.083372° grid, latitude **descending**.
- Variables: `npp` (Net Primary Productivity, mgC m^-2 day^-1).
- License/attribution: other (http://sites.science.oregonstate.edu/ocean.productivity/); attribute as "Oregon State University Ocean Productivity (Behrenfeld & Falkowski 1997 VGPM; NASA MODIS-Aqua)".
