# NASA GPM IMERG — monthly global precipitation

STAC Collection describing (not mirroring) the `IMERG_monthly_global_precip` ERDDAP griddap dataset. Monthly accumulated precipitation from the NASA Global Precipitation Measurement mission IMERG product, 0.1 degree global.

- Producer: NASA Global Precipitation Measurement (GPM) mission (https://gpm.nasa.gov/data/imerg).
- Source server: `https://erddap.marine.usf.edu/erddap` (USF IMaRS; config [USF-IMARS/erddap-config](https://github.com/USF-IMARS/erddap-config)).
- Server used here: `https://erddap.oceanmetrics.io/erddap` (re-served with CORS + Parquet).
- Coverage: 1998-01-01 to 2025-09-01, step P1M, 0.1° grid, latitude **descending**.
- Variables: `precipitation` (precipitation, mm); `precipitationQualityIndex` (Precipitation Quality Index, none); `randomError` (Monthly Accumulated Precipitation Random Error, mm).
- License/attribution: CC0-1.0; attribute as "NASA GPM IMERG".

Generated by [`catalog/build_erddap_collections.ts`](../../../build_erddap_collections.ts) from the
server's `info/IMERG_monthly_global_precip/index.json`; edit that script, not this file.
