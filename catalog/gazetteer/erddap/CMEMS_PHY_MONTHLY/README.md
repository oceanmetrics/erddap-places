# CMEMS Global Ocean Physics — surface salinity (known NaN)

STAC Collection describing (not mirroring) the `CMEMS_PHY_MONTHLY` ERDDAP griddap dataset. Sea water salinity (so) at the surface level from the CMEMS global ocean physics analysis and forecast.

> **Known issue: the values on this dataset are all NaN as re-served (2026-10); use cmems_salinity instead. Not precomputed.**

- Producer: Copernicus Marine Service (CMEMS) / Mercator Ocean International (https://marine.copernicus.eu).
- Source server: `https://erddap.marine.usf.edu/erddap` (USF IMaRS; config [USF-IMARS/erddap-config](https://github.com/USF-IMARS/erddap-config)).
- Server used here: `https://erddap.oceanmetrics.io/erddap` (re-served with CORS + Parquet).
- Coverage: 2022-06-01 to 2025-05-18, irregular time steps, 0.083333° grid, latitude **ascending**.
- Depth: Depth (positive down; 1 levels); the app and the precompute slice the surface level, `erddap-places:depth` = 0.494025 m.
- Variables: `so` (so, PSU).
- License/attribution: other (https://marine.copernicus.eu/user-corner/service-commitments-and-licence); attribute as "E.U. Copernicus Marine Service Information (CMEMS)".

Generated by [`catalog/build_erddap_collections.ts`](../../../build_erddap_collections.ts) from the
server's `info/CMEMS_PHY_MONTHLY/index.json`; edit that script, not this file.
