# CMEMS Global Biogeochemistry — monthly zooplankton

STAC Collection describing (not mirroring) the `cmems_biogeochem_zoo` ERDDAP griddap dataset. Monthly mean total zooplankton carbon (zooc) on 50 depth levels from the CMEMS global biogeochemistry analysis and forecast (0.25 degree).

- Producer: Copernicus Marine Service (CMEMS) / Mercator Ocean International (https://marine.copernicus.eu).
- Source server: `https://erddap.marine.usf.edu/erddap` (USF IMaRS; config [USF-IMARS/erddap-config](https://github.com/USF-IMARS/erddap-config)).
- Server used here: `https://erddap.oceanmetrics.io/erddap` (re-served with CORS + Parquet).
- Coverage: 2024-09-16 to 2025-02-15, step P1M, 0.25° grid, latitude **ascending**.
- Depth: Depth (positive down; 50 levels); the app and the precompute slice the surface level, `erddap-places:depth` = 0.49402538 m.
- Variables: `zooc` (Total Zooplankton, MMol' 'M-3).
- License/attribution: other (https://marine.copernicus.eu/user-corner/service-commitments-and-licence); attribute as "E.U. Copernicus Marine Service Information (CMEMS)".
