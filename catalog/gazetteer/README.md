# Ocean Metrics gazetteer

Marine place polygons (NOAA sanctuaries, MarineRegions MRGID, ProtectedSeas PSGID) as GeoParquet + PMTiles, plus ERDDAP dataset descriptions for computing place statistics in the browser (DuckDB-WASM).

Published at `https://storage.oceanmetrics.io/gazetteer/`.

## Collections

- [`places/`](places/collection.json) — 20 marine place polygons as GeoParquet (`places.parquet`)
  and PMTiles (`places.pmtiles`). License: CC-BY-4.0 (our derived files). Upstream sources: NOAA
  Office of National Marine Sanctuaries (public domain), MarineRegions.org (CC-BY 4.0), ProtectedSeas
  (see their terms).
- [`erddap/dhw_5km/`](erddap/dhw_5km/collection.json) — NOAA Coral Reef Watch daily 5km SST + DHW
  (live, PacIOOS ERDDAP).
- [`erddap/jplMURSST41/`](erddap/jplMURSST41/collection.json) — JPL MUR SST v4.1, 0.01° daily
  (upstream NOAA CoastWatch is live; our re-serving mirror is not yet live).

## How to read

- Places: `SELECT * FROM read_parquet('https://storage.oceanmetrics.io/gazetteer/places/places.parquet')`
  in DuckDB; load `places.pmtiles` into MapLibre GL for rendering.
- ERDDAP: read a `collection.json`'s `griddap` asset template and build a query URL — see
  [`AGENTS.md`](AGENTS.md).
